# 🤝 Đóng góp vào Dự án MLOps Phone Price Prediction API

Cảm ơn bạn đã quan tâm đến việc đóng góp! ❤️

## Cách đóng góp

1. Fork repo và clone về máy:
```bash
git clone https://github.com/<your-username>/mlops-phone-price-prediction-api.git
```

2. Tạo nhánh mới:
```bash
git checkout -b feature/<tên-tính-năng>
```

3. Cài Pre-commit và chạy kiểm tra:
```bash
pre-commit install
pre-commit run --all-files
pytest
```

4. Commit theo convention:
```bash
git commit -m "feat: thêm pipeline validate model"
```

5. Gửi Pull Request về nhánh main

Style Guide
+ Format code với black
+ Lint với ruff
+ Test với pytest

Mọi đóng góp đều được hoan nghênh!
